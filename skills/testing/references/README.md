- `tdd-iron-laws.md`: TDD loop reminders, the two valid RED paths (runtime and compile-time), verification discipline, and durable RED/GREEN checkpoints in git.
- `testing-anti-patterns.md`: smell-and-fix pairs with code — mock-only assertions, testing the language or a library, implementation-pinned tests, private-state reach-in, absence tests after a removal, tautological and unreachable assertions, rubber-stamp snapshots — plus a review checklist.
- `test-report-template.md`: consistent structure for reporting results.
- `performance-regression.md`: perf budgets and CI guardrails.
- `qa-practice-compact.md`: exploratory testing charters and risk-based focus.
- `static-grep-invariant-tests.md`: grep-based regression tests for known-bad textual signatures (forbidden literal pairings, deprecated write paths).
- `flaky-test-triage.md`: reading a rerun signature, the concurrent-run contention checklist, and the fix policy for intermittent and order-dependent failures.
- `provenance.md`: sources for the test-admission gate, the failing-test rules, and the newer anti-pattern entries; what was not carried; chosen defaults.
